Portfolio — static scaffold

This folder contains a simple one-page static portfolio (dark theme) with Home, Projects, and Contact sections.

Files:
- index.html — main page
- styles.css — styles
- script.js — tiny JS for nav and smooth scroll

How to use:
1. Open C:\Dev\Git_GitHub_Tutorial\portfolio\index.html in a browser to preview.
2. Replace project placeholders in the Projects section with your project titles/descriptions and links.
3. Update social links in the Contact section.

If you want a hosted site, use GitHub Pages, Netlify, or Vercel. For forms or contact submission, a third-party service (Formspree, Getform) or a backend will be required.
